# Takkamittari

A small project for using [Seeed Studio XIAO ESP32C3](https://www.seeedstudio.com/Seeed-XIAO-ESP32C3-p-5431.html) board with a temperature probe to measure temperature of one of the ventilation shafts of the fireplace of our house, and send the data to Home Assistant over MQTT.

## Hardware

Components used in the project:

* ESP32C3 Microcontroller
  * Seeed Studio XIAO ESP32C3
  * https://partco.fi/tuote/seeed-studio-xiao-esp32c3-357
* WiFi Antenna
  * 2,4GHz U.FL-Ipex 100mm
  * https://partco.fi/tuote/wifi-antenni-2-4ghz-u-fl-ipex-100mm-2063
* LED display
  * Joy-IT SBC-LCD16x2
  * https://partco.fi/tuote/lcd-n%C3%A4ytt%C3%B6-2x16-sinivalko-i2c-liit%C3%A4nt%C3%A4-5193
* Temperature probe
  * Elecrow STH01102S
  * https://partco.fi/tuote/l%C3%A4mp%C3%B6anturi-18b20-valettu-johto-90cm-11258


The 3D printed case design was done by having a chat with Gemini 4 Argon.
